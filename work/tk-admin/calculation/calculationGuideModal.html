*결제구분은 결제내용에 따라 다음과 같이 구분하여 입력해주시면 됩니다.

A = 고객이 TK여행상품, K-POP등 해외카드 결제할 경우 - NICE페이

B = 고객이 TK여행상품, K-POP등 알리, 위챗으로 결제할 경우 - NICE페이

C = 고객이 TKTRAVEL,여행대장에서 상품 무통장 입금시(계산서미발행) - 하나은행

C1 = 고객이 TKTRAVEL,여행대장에서 상품 무통장 입금시(계산서발행) - 하나은행

C2 = 고객이 TKTRAVEL,여행대장에서 상품 무통장 입금시(현금영수증) - 하나은행

D = 거래처에서 TK여행상품, K-POP등 무통장 입금시(영세율) - 국민은행

E = 고객이 여행대장에서 국내 카드로 결제할 경우 - 토스페이

F = 고객이 베네피아에서 국내 카드로 결제할 경우 - NICE페이

G = 고객이 베네피아에서 포인트로 결제할 경우 - KCP페이

H = 거래처(국내쇼셜)에서 여행대장 상품 구매 후 정산시 - 국민은행

*랜드비용에는 여행에 소요된 순수 여행경비금액만을 기재하고, 신용카드수수료, 가이드비용, 모객수수료 비용 등은 별도 비용처리 대상이므로 랜드비용에 포함시키면 안됩니다.
