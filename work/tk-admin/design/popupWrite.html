  • "이미지 불러오기" 를 통해 이미지 선택
  • "맵레이어 생성"을 클릭하여 새로운 spot영역을 생성 (여러개 생성시는 생성하고자 하는 갯수만큼 클릭)

  • 이미지 위에 생성된 맵영역을 드래그하여 원하는 위치로 드래그
  • 맵영역 크기 설정은 박스 귀퉁이를 드래그하면 됨
  • "Make Code"버튼을 클릭하면 맵코드 생성
  • "Preview"버튼 클릭하면 링크된 내용의 미리보기 할 수 있음
