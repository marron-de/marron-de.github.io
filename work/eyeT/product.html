핵심 기능 소개(Feature Highlight)

제품의 차별화된 기능 요약

EyeT’s core features 01

워크플로우 공유 (Workflow Sharing)

사용자는 자신만의 워크플로우를 설계하고 자동화할 수 있습니다.

만들어진 워크플로우는 다른 사용자와 간편하게 공유할 수 있으며, 공유받은 사용자는 복잡한 설정 과정 없이 데이터만 교체해 즉시 동일한 흐름으로 활용할 수 있습니다.

이를 통해 반복 작업을 최소화하고, 효율적인 분석 프로세스를 손쉽게 확산시킬 수 있습니다.

EyeT’s core features 02

시각화 (Map & Chart Visualization)

•지도 시각화
GIS엔진 기반으로 공간 데이터를 시각적으로 분석
위치, 범위, 거리, 상권 등 공간적 패턴을 쉽게 탐색
지오메트리(Geometry) 연산 지원: 버퍼(Buffer), 교차(Intersection), 병합(Merge), 공간결합(Spatial Join) 등 지원을 합니다.

•차트 시각화
기본 통계형, 분포형, 비교형, 시계열형, 계층형, 공간형, 관계형 시각화를 합니다.

EyeT’s core features 03

AI 자동화 · 스케줄링 (AI Automation · Scheduling)

워크플로우를 설정된 시간에 맞춰 자동으로 실행합니다.

이를 통해 분석 과정을 주기적으로 수행하고, 결과를 보고서 형태로 생성하거나 데이터베이스에 자동으로 입력·업데이트할 수 있습니다.

반복적인 업무를 자동화함으로써 효율적인 데이터 운영 환경을 구축할 수 있습니다.

EyeT’s core features 04

자동보고서 생성 (Automatic Report Generation)

데이터 정제와 모델링 과정을 통해 도출된 분석 결과를 LLM이 자동으로 보고서 형태로 생성합니다.

사용자는 시각화된 결과를 통해 핵심 인사이트를 빠르게 파악하고, 이를 즉시 업무에 활용할 수 있습니다.

반복적인 보고서 작성 과정을 자동화하여, 분석에서 실행까지의 시간을 단축합니다.
